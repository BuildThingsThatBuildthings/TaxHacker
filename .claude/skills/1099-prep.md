# 1099 Preparation

Identify contractors/vendors who need 1099-NEC forms and prepare the filing report.

## Arguments (optional)
- `--year YYYY` — tax year (defaults to previous year)

## Workflow

1. **Get 1099 summary**:
   ```
   npx tsx src/cli/stats.ts 1099-summary --year YYYY
   ```

2. **Present the 1099 report**:

   ```markdown
   # 1099-NEC Preparation — 2025
   **Threshold:** $600.00

   ## Vendors Requiring 1099
   | Vendor | Total Paid | Tx Count | Tax ID | W-9 |
   |--------|-----------|----------|--------|-----|
   | John Smith Consulting | $12,500.00 | 6 | Yes | Yes |
   | Freelance Designer LLC | $3,200.00 | 4 | No | No |
   | Video Production Co | $8,750.00 | 3 | Yes | No |

   ## Summary
   | | Count |
   |---|---|
   | Vendors needing 1099 | 3 |
   | Missing Tax ID | 1 |
   | Missing W-9 | 2 |
   | Vendors below threshold | 15 |

   ## Action Items
   - Request W-9 from Freelance Designer LLC (missing tax ID and W-9)
   - Request W-9 from Video Production Co (has tax ID but no W-9 on file)
   ```

3. **Suggest actions**:
   - Update contacts with missing tax IDs
   - Request W-9 forms from vendors
   - Remind about 1099 filing deadline (January 31)

4. **Offer to update contacts**:
   ```
   npx tsx src/cli/contacts.ts update <id> --tax-id "XX-XXXXXXX" --w9-received
   ```

## Important Rules
- 1099-NEC threshold: $600 per vendor per tax year
- Only applies to non-corporate vendors (generally)
- Filing deadline: January 31 of the following year
- Penalties for late or missing 1099s can be significant
- Amounts are in cents. Format for display: divide by 100
